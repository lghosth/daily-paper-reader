## 摘要
个性化联邦学习（PFL）是一种有前景的分布式设备协同学习范式，其中边缘节点在不共享原始数据的情况下协同训练个性化模型。尽管PFL通过学习客户端特定模型解决了数据异质性，但在带宽受限系统中交换高维参数时，仍面临显著的上行和下行通信开销。最近的一位（one-bit）方法实现了极端压缩，但通常依赖于应用于整个模型的单一阈值规则。这种设计有两个局限性：首先，它忽略了参数分布和量化敏感性在逐层上的差异；其次，单一阈值仅提供粗略的二进制信息，无法捕捉参数分布中的细微变化。为解决这些问题，我们提出了一种通过逐层多阈值随机草图实现的通信高效PFL框架。在所提出的方法中，每一层被分配其自身的量化阈值集合，使得压缩表示能够适应层特定的统计特性，同时使用多个区间为草图参数提供更精细的低比特描述。该方法利用紧凑的低比特草图支持双向通信，并与现有的一位压缩方法相比，改善了通信-精度权衡。

## Abstract
Personalized federated learning (PFL) is a promising paradigm for collaborative learning over distributed devices, where edge nodes collaboratively train personalized models without sharing raw data. Although PFL addresses data heterogeneity by learning client-specific models, it still suffers from substantial uplink and downlink communication costs when exchanging high-dimensional parameters in bandwidth-constrained systems. Recent one-bit methods achieve extreme compression, but they usually rely on a single thresholding rule applied to the whole model. This design has two limitations. First, it overlooks layer-wise differences in parameter distributions and quantization sensitivities. Second, a single threshold provides only coarse binary information and cannot capture fine-grained variations in parameter distributions. To address these issues, we propose a communication-efficient PFL framework via layer-wise multi-threshold random sketching. In the proposed method, each layer is assigned its own set of quantization thresholds, so that the compressed representation can adapt to layer-specific statistics while using multiple intervals to provide a finer low-bit description of sketched parameters. The proposed method supports bidirectional communication using compact low-bit sketches and improves the communication-accuracy tradeoff compared with existing one-bit compression approaches.

## 1. 核心问题与研究动机

- **背景**：联邦学习（FL）支持在分布式设备间协作训练模型而不共享原始数据，广泛应用于边缘智能、物联网和车载网络。个性化联邦学习（PFL）进一步解决数据异质性，让每个客户端在本地数据分布上学习个性化模型。
- **核心问题**：PFL 在带宽受限的系统中反复交换高维模型参数，造成巨大的上行和下行通信瓶颈。极端的“一位（one-bit）”压缩方法虽然能大幅降低通信开销，但存在两个关键缺陷：
  1. **忽略逐层差异**：现代深度神经网络不同层的参数分布和量化敏感性差异显著（论文通过简单 DNN 训练动态可视化了浅层 fc1.weight 分布集中而深层 fc2.weight 分布更宽的现象），统一压缩规则难以匹配各层的异构统计特性。
  2. **信息粒度粗糙**：单阈值只能提供二值信息（正/负），无法捕捉层内参数分布的细微变化，量化表达能力不足。
- **研究缺口**：现有的一位压缩方法（如 pFed1BS）采用层不可知的单阈值规则，且通常适用于整模型统一处理；而许多通信压缩方法仅关注上行链路，服务器端仍需以高精度广播完整模型，缺少面向 PFL 的**双向极端低比特通信**与**结构自适应量化**的协同设计。

## 2. 方法论：pFedLMS 框架

- **总体思想**：提出逐层多阈值随机草图（Layer-Wise Multi-Threshold Random Sketching, LMTRS）替代层不可知、单阈值的二值压缩规则。
  - **逐层自适应**：为每一网络层分配独立的有序阈值集合，使量化几何适配层间参数分布差异。
  - **多阈值细化**：利用 T 个阈值将草图参数空间划分为 (T+1) 个区间，提供比二值更精细的低比特描述。
  - **双向压缩**：通过 (T+1) 进制编码实现上行和下行通信均仅需传递紧凑草图消息。

## 6. 主要结论

- pFedLMS 通过逐层多阈值随机草图实现了**自适应、细粒度**的低比特双向通信压缩，显著优于一位单阈值基线（单阈值随机草图 pFed1BS、符号压缩等）。
- 在 α=0.5 设定下，CIFAR-10 精度较 pFed1BS 提升 9.17 个百分点，CIFAR-100 提升 13.49 个百分点；α=0.1 下 CIFAR-100 提升 10.85 个百分点。
- 在多个数据集上接近甚至达到全精度 FedAvg 的精度，但通信成本大幅降低：MNIST/FMNIST 仅约 0.38 MB/轮，较 FedAvg 降低约 98.8%；CIFAR-100 约 25.05 MB/轮，降低约 98.3%。
- 组件消融证明层式设计和多阈值机制互补：单一组件提升有限，两者联合带来最大增益。
- 随 T 增大精度递增，但边际增益递减（T=1→2 增幅最大），说明较少的阈值数即可捕获大部分有用的共识信息。

## 7. 优点

- **创新性**：首次将逐层多阈值量化引入随机草图式 PFL，突破以往一位压缩“层不可知—全模型统一阈值”的范式限制，为通信-精度权衡提供了新的设计维度。
- **理论完备**：提供从多数投票最优性、区间一致性解释、分辨率增益到非凸收敛界的完整理论链条；对共识/阈值/草图算子的跨轮漂移有显式刻画。
- **双向压缩协议设计精巧**：(T+1)-ary 编码在小开销下实现无信息损失的底层通信；草图矩阵由共享随机种子生成本地重建，避免显式传输；层间均值/方差统计与阈值开销仅为 O(L+LT)，可忽略。
- **实验设计较全面**：覆盖多种非 IID 强度、5 个数据集、多种代表性基线、组件消融与超参敏感性，结论可信度较高。
- **表述清晰**：问题动机图示直观，系统与通信协议图完整，算法伪代码详细。

## 8. 不足与局限

- **实验模型与现实差距**：仅在 DNN/VGG 规模上验证，未涵盖 Transformer 或大规模基础模型，结论向现代深度架构的推广性存疑。

- **数据异质性覆盖有限**：只用 Dirichlet 标签偏移模拟非 IID，缺少特征偏移、数量倾斜和真实分布漂移（如时间/季节变化）等更复杂的异质性场景。
