## 摘要
客户端异构性在个性化联邦图学习中既带来机遇也带来风险。其他子图拥有的知识可能补充接收方的本地模型，但不兼容的迁移可能覆盖可靠的预测。一次性通信加剧了这种紧张关系，因为不合适的服务端返回无法在事后修正。我们提出了PACE，它将协作知识视为对完整本地预测器的紧凑校正，而非替代品。每个客户端上传一个秩为r的更新载体和传播消息矩的对角草图。服务端利用它们构建传播感知的、以接收方为中心的校正，同时接收方保留其完整的本地模型。凸负对数似然校准（CNLL）随后使用验证节点在本地和外部logits之间选择一个系数；模型参数保持固定，且不发送反馈。在秩为6时，个性化返回占据六个评估数据集密张量字节的9.6-17.6%。校正获得非零权重，并在五个数据集上相较于本地模型提高了准确率（Accuracy）和加权F1分数；在ogbn-arxiv上，CNLL将零预测权重分配给校正，并精确保留本地预测。将相同的CNLL规则应用于三个引文数据集上的匹配基线，并不能解释这些增益。因此，核心结果是：当接收方证据支持时，一个小的传输校正可以增强完整的本地模型，否则保持本地预测不变。

## Abstract
Client heterogeneity creates both an opportunity and a risk in personalized federated graph learning. Knowledge held by other subgraphs may complement a receiver's Local model, but an incompatible transfer can override reliable predictions. One-shot communication sharpens this tension because an unsuitable server return cannot be corrected later. We introduce PACE, which treats collaborative knowledge as a compact correction to a complete Local predictor rather than as its replacement. Each client uploads a rank-r update carrier and a diagonal sketch of propagated message moments. The server uses them to construct a propagation-aware, receiver-anchored correction, while the receiver retains its full Local model. Convex negative-log-likelihood calibration (CNLL) then selects one coefficient between Local and External logits using validation nodes; model parameters remain fixed and no feedback is sent. At Rank-6, personalized returns occupy 9.6-17.6% of dense tensor bytes across the six evaluated datasets. The correction receives nonzero weight and improves both Accuracy and weighted-F1 over Local on five datasets; on ogbn-arxiv, CNLL assigns zero predictive weight to the correction and preserves Local predictions exactly. Applying the same CNLL rule to matched baselines on three citation datasets does not account for these gains. The central result is therefore that a small transported correction can augment a complete Local model when receiver evidence supports it while leaving the Local prediction unchanged otherwise.

### 一、核心问题与研究动机
#### **问题背景与研究动机**
个性化联邦图学习（Personalized Federated Graph Learning, FGL）面临来自客户端异构性的双刃剑挑战，核心平衡点在于：

- **互补机遇**：其他客户端拥有的子图（Subgraph）知识可能填补本地社区的缺失信息，促进本地模型的完善。
- **负迁移风险**：结构差异或数据分布不兼容的客户端外部模型可能覆盖或干扰本地模型的可靠预测。

此项研究聚焦于更为严格的**一次性（One-Shot）通信**协议。在此框架下，通信仅有客户端上传与服务器下发各一次，不存在后续轮次修正错误的机会。因此，如何设计一种"紧凑且安全"的协作知识传输形式，使接收端既能利用外部有益的补充信息，又能隔离或拒绝有害的影响，成为亟待解决的核心问题。

> **核心诉求**：解决一次性通讯中，外部协作知识如何在不破坏完整的本地模型的前提下，高效地利用起来。

### 二、方法论：PACE 框架
PACE的核心思想在于**将对跨客户端知识的利用视为对本地模型的"微型校正"而非"模型取代"**，其流程可分为两大设计环节：**传输（Transport）**与**校准（Calibration）**。

#### 1. 核心技术思想与流程
PACE通过一次上传与一次下载，实现紧凑的知识传输与个性化采纳。

- **步骤1：本地训练并生成上传载体**
    - 每个客户端在本地数据上训练出完整的GCN模型（W\_L）。
    - 客户端计算相对公共初始化参数的更新量（$$\Delta_i = W_i^L - W_0$$）。
    - 通过**截断SVD分解**，将更新量压缩为秩-r的低秩载体（$$\bar{\Delta}_i = P_6(\Delta_i)$$），用于传输。
    - 同时，计算训练数据上的**传播感知矩草图**：经过邻接传播后的消息嵌入对角二阶统计量（C_j），该信息可以捕捉图传播结构对参数的重要性，作为端侧模型在合并中的重要度度量。

- **步骤2：服务端共识构建**
    - 服务端收集所有客户端的低秩载体和传播矩草图。
    - 借助**RegMean**概念（传播感知的加权平均），计算出所有客户端自包含的加权平均共识方向。该方向考虑了每个客户端传播激活的矩信息（权重系数固定为均匀权重1/K）。

- **步骤3：构造接收端锚定校正并下发**
    - 对接收端i，服务端计算共识与本地客户端的差异，作为该客户端独有的个性化更新量（$$\Gamma_i = \Delta_C - \bar{\Delta}_i$$），再次进行低秩压缩后下发。这形成了**锚定于本地模型的校正项**（Receiver-Anchored Correction）。
    - 客户端接收后，将校正项加到自身的完整模型上，得到外部（External）模型 $$W_E = W_L + \hat{\Gamma}_i$$。

- **步骤4：客户端侧凸NLL校准**
    - 不进行参数迭代，使用验证集对模型输出进行**凸负对数似然（CNLL）校准**。客户端仅优化得到一个权重系数（$$\alpha$$），控制本地模型与外部模型的logits混合比例。
    - 该系数$$\alpha=0$$时将完全保留本地模型预测，等于1则全盘用外部模型，若设置在(0,1)之间则按比例折衷。

#### 2. 核心公式与技术细节
- **Moment Sketch 的传播感知**：在GCN中，节点表示经过多次传播，PACE将传播算子和激活矩阵结合，在不同特征维度上得到各节点尺度不敏感的矩草图，从而在模型合并中更准确地顺应结构多样性。
- **服务端共识与校正策略**：公式采用带权重的二次规划最小二乘，其闭式解是对各模型按加权矩加权求平均。其核心在于服务端不为每个客户端训练特定模型，而是通过计算全局共识与本地模型的差值来生成**局域化的校正方向**。
- **CNLL（Convex Negative Log-Likelihood Logit Calibration）**：
    - `z = (1-α)z_L + αz_E`
    - 风险关于α是**凸函数**（由二阶导数≥0保证），因此CNLL很容易通过边际二分搜索得到全局最优解。该过程只用验证集，不读测试标签，不强求下载模型。
    - CNLL有严格的信息几何解释：它是两个分布间的反KL散度加权重心（weighted reverse-KL barycenter），优化过程等效于在测试节点上做模型置信度加权。

### 六、主要结论
1. **有效性证明**：PACE在五大常规基准（Cora、CiteSeer、PubMed、CS、Computers）上同时超越了Local基线以及所有单协议对照，同时服务端返回仅需数据量的 9.6%–17.6%（Rank-6）。

### 七、方法优点
- **模型保留性**：与传统的替换式模型聚合不同，PACE把完全不受损失的全量本地模型保留在客户端内部，采用"建议/补充"的非破坏式架构，极大规避了一性通信中的灾难性遗忘。
- **补足充分的个性化机制**：通过设置一个可调节的系数α，在参数域不改变的前提下实现了更好的跨域组合，通过可证凸性的算法实现零成本强收敛，在计算端有严密数学推导支撑。
- **通信极大压缩**：低秩+二阶矩，实现Rank-6 仅占稠密模型 9.6%—17.6% 的极好带宽成绩。
- **自动保护机制**：能够针对不适合协作的场景（如odbn-arxiv）自动返回 α=0，这相当于解决了联邦学习个性化中“客户拒绝知识”的一次性且高纠偏的手段。
