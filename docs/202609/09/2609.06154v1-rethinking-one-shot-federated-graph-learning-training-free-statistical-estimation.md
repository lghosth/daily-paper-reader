## 摘要
一次性联邦图学习通常旨在通过单轮通信，在客户端之间具有断开的子图上训练图神经网络（GNN）。现有方法主要是在本地GNN训练不可或缺的前提下设计先进的优化策略。然而，经验观察表明，在极端非独立同分布（non-IID）条件下，本地GNN训练遭受严重的跨客户端表示错位，成为错误的主要来源而非补救措施。受此启发，我们将一次性联邦图学习重新表述为统计估计问题。我们提出了SPEAR（具有自适应可靠性的统计原型估计），这是一个完全免训练的框架，直接在原始特征空间中从局部图计算拓扑平滑的类原型。服务器随后使用样本大小自适应的收缩估计器聚合这些原型，该估计器降低不可靠局部估计的权重，从而生成稳健的全局类原型。在七个基准上的广泛实验表明，SPEAR在极端异质性下始终达到最先进的准确率。此外，SPEAR相比所有基线至少实现一个数量级的加速，相比生成式和基于蒸馏的方法甚至达到数个数量级的加速。我们的发现表明，免训练的统计估计而非本地GNN优化，是稳健高效的一次性联邦图学习的关键。代码可在 https://github.com/Yodeesy/SPEAR 获取。

## Abstract
One-shot federated graph learning generally aims to train Graph Neural Networks (GNNs) across clients with disconnected subgraphs in a single communication round. Existing methods predominantly design advanced optimization strategies under the premise that local GNN training is indispensable. However, empirical observations reveal that under extreme non-IID conditions, local GNN training suffers from severe cross-client representation misalignment, becoming a major source of error rather than a remedy. Motivated by this, we reformulate one-shot FGL as a statistical estimation problem. We propose SPEAR (Statistical Prototype Estimation with Adaptive Reliability), a completely training-free framework that directly computes topology-smoothed class prototypes from local graphs in the original feature space. The server then aggregates these prototypes using a sample-size-adaptive shrinkage estimator that down-weights unreliable local estimates, producing robust global class prototypes. Extensive experiments across seven benchmarks demonstrate that SPEAR consistently achieves state-of-the-art accuracy under extreme heterogeneity. Moreover, SPEAR delivers at least an order-of-magnitude speedup over all baselines, reaching several orders of magnitude against generative and distillation-based methods. Our findings suggest that training-free statistical estimation, rather than local GNN optimization, provides the key to robust and efficient one-shot federated graph learning. The code is available at https://github.com/Yodeesy/SPEAR .

## 1. 核心问题与研究动机

- **背景**：一次性联邦图学习（One-Shot FGL）旨在仅通过**单轮通信**，在客户端之间互不相连的本地子图上完成协作学习。现实应用（如金融网络、生物化学交互）中的图数据通常高度互联，但跨客户端边天然缺失，导致严重结构异质性。
- **核心观察**：已有方法（如 FedSD2C、GHOST、OASIS）均以**本地 GNN 训练不可避免**为前提。然而作者发现一个反直觉现象——在极端 non-IID（Dirichlet β=0.05）条件下，本地 GNN 训练会过拟合客户端特有的标签分布与结构模式，造成**严重的跨客户端表示错位**；由于单轮通信无法迭代纠正，这类错位反而成为主要误差来源。图 2 与 Silhouette Score 定量实验表明，原始特征空间天然具有语义聚类结构，而参数化训练（FedAvg、FedProto、FedGTA 等）将其严重破坏（分数跌至 −0.29 以下）。
- **核心问题**：在极端一次性联邦图学习场景中，**本地参数优化是否真的必要？**
- **整体思路**：将 one-shot FGL 重新表述为**纯统计估计问题**，彻底放弃本地梯度训练，证明“免训练的统计估计”比“本地 GNN 优化”更稳健高效。

## 2. 方法论：SPEAR

**核心思想**：完全训练无关、零梯度、单轮通信。本地端只做拓扑平滑的特征传播与类原型统计；服务器端对收到的原型做可靠性自适应的收缩估计（受 James–Stein 估计启发）。

### 2.1 本地端：拓扑平滑的类原型估计（Topology-Smoothed Prototype Estimation）
- 去除 GNN 中所有可训练变换与非线性激活，只保留**结构传播算子**；
- 对原始特征做 L2 归一化得 X̃_k，构造带自环的行归一化转移矩阵 Â_k = D̃⁻¹(A_k + I)；
- 使用**截断个性化 PageRank（PPR，即 APPNP 式传播）**做 T 步迭代（默认 T=2）：
  Z⁽ᵗ⁺¹⁾_k = (1−α)X̃_k + αÂ_k Z⁽ᵗ⁾_k，其中 α 为传播权重（默认保守取值 0.15）；
- 客户端对每个本地观测到的类 c 取平均，得到**本地原型** p_{k,c} = (1/|V_{k,c}|) Σ z_{k,i}；
- 仅上传原型集合 P_k 与各类样本量 n_{k,c}，通信量为 O(CF)。

### 2.2 服务器端：可靠性自适应收缩估计（Reliability-Adaptive Shrinkage）
- 为每个本地原型构造 **peer mean**（其余客户端的等权均值）：p̄_{−k,c} = (1/(|S_c|−1)) Σ_{j∈S_c\{k}} p_{j,c}；
- 通过收缩因子将不可靠本地估计拉向 peer 均值：p̃_{k,c} = (1−λ_{k,c})p_{k,c} + λ_{k,c} p̄_{−k,c}；
- 收缩权重由样本量自适应决定：**λ_{k,c} = 1/(1+γn_{k,c})**——样本越少、不确定性越大、收缩越强；
- 理论支撑：将本地原型建模为真实质心加噪声（噪声方差反比于样本量，即 σ²_{k,c}=σ₀²/n_{k,c}），Proposition 1 证明最优收缩权重为 λ* = σ²_{k,c}/(σ²_{k,c}+τ²)，且收缩后 MSE 严格小于未收缩局部估计；
- 聚合：服务器以样本量加权平均 + L2 归一化构造全局原型 g_c = Norm( Σ n_{k,c} p̃_{k,c} / Σ n_{k,c} )；
- 推理：测试节点同样经 PPR 平滑后，与各类全局原型做**余弦相似度匹配**（零梯度非参数分类器）。

### 2.3 算法流程（对应论文 Algorithm 1）
1. 各客户端并行：L2 归一化 → T 步 PPR 扩散 → 按类平均计算本地原型 → 上传原型与样本计数；
2. 服务器端：对每个类计算 peer mean → 按样本量计算收缩系数 → 合成全局原型 → L2 归一化；
3. 全局推理：余弦相似度 argmax 分类。

## 6. 主要结论与发现

1. **训练反而有害**：极端异构下，本地 GNN 训练导致的跨客户端表示错位是主要误差来源；原始特征空间的类结构比任何参数化变换后的表征都更可靠。
2. **SPEAR 性能显著领先**：7 个基准上全部达到 SOTA，尤其优势在极端异构下最大。
3. **效率呈数量级提升**：相比所有基线至少快一个数量级（如表 3 中 42×~111× 加速），相比生成式/蒸馏式方法快数个数量级；通信量从 MB 级降至 KB 级（CiteSeer 从 7246 MB 降至 18.8 KB）。
4. **鲁棒性强**：对结构扰动（ρ=0.5）与特征扰动（η=0.5）几乎不敏感；对拜占庭攻击天然抵抗；不依赖具体超参数。
5. **统计估计优于梯度优化**：PPR 平滑 + James-Stein 式收缩的互补组合，能产出比纯均值聚合更小误差的全局原型（原型误差降低近一个数量级），验证了“免训练统计估计”这一范式的价值。

## 7. 优点

- **概念性贡献突出**：从“训练前提不可动摇”的主流思路中跳出，首次以纯统计估计视角回答 one-shot FGL 的表示错位问题，并提供了完整的实证支撑（UMAP + Silhouette 量化显示训练方法破坏表征结构）；

- **工程落地价值高**：单轮 KB 级通信、零训练开销，契合边缘部署场景；代码已开源；
- **实验与讨论全面**：包含扰动鲁棒性、异构度、客户端规模、超参扫描、拜占庭攻击、异嗜图局限、模型容量边界等多角度验证；

## 8. 不足与局限

- **同嗜偏好与拓扑利用天花板**：PPR 本质是低通滤波器，在异嗜图上传播反而混入异类噪声；作者亦称当前帧缺失**异嗜感知（自适应高通/带通）**机制，无法建设性利用异嗜边；
- **容量边界**：当数据接近 IID（β→1.0）时，深度训练方法（FedAvg 200 轮）在 Cora 上可反超 SPEAR——仅“统计线性估计”并不普适，更接近一种极端不均衡下的“鲁棒保险”而非通用替代；
- **无形式化隐私保证**：虽仅上传类原型、暴露面小，但原型仍可能受重构或成员推断攻击；而加噪差分隐私会增加小样本方差，与收缩去噪目标直接冲突，缺乏相应论证；
- **跨客户端边信息完全缺失**未作处理；对客户端拓扑结构本身（如度数、密度）也未建模；
- **超参数需人工设定**：γ 虽不敏感但不可为零，α 依赖图同嗜度且默认值是在同/异嗜间妥协的本数据保守值；
- **小样本极端的统计噪声未消**：当某类只在极少数客户端出现（|S_c| 很小）时，peer mean 自身方差高，收缩依据（同等对待各 peer 的简单均值）并不充分；
- **可复现细节缺失**：未交代 GPU 数量、总运行时长、能耗，也未提供与训练类方法同等的计算资源说明。
