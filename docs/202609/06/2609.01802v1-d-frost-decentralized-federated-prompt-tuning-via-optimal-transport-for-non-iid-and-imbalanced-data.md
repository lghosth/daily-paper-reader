## 摘要
提示调优通过冻结预训练骨干并仅更新一小部分可学习提示，为适配基础模型（FM）提供了一种参数高效的方法。这一特性使提示调优特别适用于去中心化联邦学习（DFL），因为在DFL中交换完整模型更新的代价可能过高。然而，在DFL中进行提示调优会带来新的挑战。从异质本地数据中学习到的提示集在索引上可能不对齐，这使得标准的去中心化平均方法不适用。此外，算法应在理论上保证实现共识并朝共享目标取得进展。在这项工作中，我们首次研究了DFL中的提示调优。我们将去中心化提示调优形式化为一个基于Wasserstein距离的优化问题，关注提示测度，该测度考虑了提示的集合值结构。随后，我们提出了D-FROST，一种基于最优传输（OT）的去中心化提示调优算法，该算法通过基于传输的匹配将邻近提示合并为紧凑的代表性提示集。我们进一步通过约束客户端间Wasserstein共识误差分析D-FROST，并建立网络级提示重心收敛到平稳点邻域的结论。在异质客户端数据上的实验验证了D-FROST在去中心化提示调优中的有效性。

## Abstract
Prompt tuning provides a parameter-efficient way to adapt foundation models (FMs) by freezing the pretrained backbone and updating only a small set of learnable prompts. This property makes prompt tuning especially suitable for decentralized federated learning (DFL), where exchanging full-model updates can be prohibitively expensive. However, prompt tuning in DFL introduces new challenges. Prompt sets learned from heterogeneous local data may not be index-wise aligned, making standard decentralized averaging unsuitable. In addition, the algorithm should be theoretically guaranteed to achieve consensus and make progress toward the shared objective. In this work, we provide the first study of prompt tuning in DFL. We formulate decentralized prompt tuning as a Wasserstein-based optimization problem over prompt measures, which captures the set-valued structure of prompts. We then propose D-FROST, an optimal-transport-based (OT-based) decentralized prompt-tuning algorithm that merges neighborhood prompts into compact representative prompt sets through transportation-based matching. We further analyze D-FROST by bounding the Wasserstein consensus error across clients, and establishing convergence of the network-level prompt barycenter to a neighborhood of stationarity. Experiments under heterogeneous client data demonstrate the effectiveness of D-FROST for decentralized prompt tuning.

### 一、核心问题与研究动机

1. **背景冲突**：去中心化联邦学习（DFL）消除了中心化服务器，客户端仅通过图拓扑与邻居通信。交换完整模型更新成本高昂，而提示调优（Prompt Tuning）只需交换轻量级提示参数、冻结预训练骨干网络，天然契合 DFL 的通信约束。

2. **核心难题**：将提示调优引入 DFL 会引发两大新挑战：
   - 不同客户端在异质本地数据上学习到的提示集在索引上互不对齐（index-wise misalignment），标准 DFL 中的按索引加权平均（如混合矩阵平均）会将语义无关的提示方向错误合并。
   - 缺乏理论保证：现有 DFL 收敛性分析都建立在坐标对齐的参数向量与欧几里得平均之上，无法直接用于无序提示集。

3. **核心含义**：作者首次将提示调优系统性地带入去中心化联邦场景，提出用 Wasserstein 距离替代欧氏参数平均来度量提示度量（prompt measure）之间的差异，将该问题形式化为**基于 Wasserstein 的分布式优化问题**，并设计 OT 算法达成共识。

### 二、方法论

#### 2.1 总体现路
将每个客户端的提示集视为嵌入空间上的经验概率测度：
\[
\mu_u^{(t)} = \frac{1}{n}\sum_{i=1}^{n} \delta_{\omega_{ui}^{(t)}}
\]
全局目标被定义为求一个共享提示测度来最小化平均客户端损失；用**网络级提示重心（barycenter）**描述集体状态，用 **Wasserstein 共识误差** 刻画网络分歧程度。

#### 2.2 核心步骤（D-FROST 算法）
每个通信轮分两步走：

1. **本地提示更新**：客户端在自己的私有数据上执行若干个 epoch 的提示优化，得到 `ω̃ᵤ⁽ᵗ⁾`。

2. **邻居合并（OT-based Merge）**：客户端收集自身与邻居的提示集，构成总集合 Ωᵤ⁽ᵗ⁾，采用最优传输将 Ωᵤ⁽ᵗ⁾ 压缩回 n 个代表性提示（代表集合大小保持恒定）。这是与现有 DFL 按索引平均最本质的区别。

#### 2.3 OT 合并的数学形式

**目标函数**（同时优化传输计划 P 和代表提示 Φ）：
\[
\min_{P\ge 0,\Phi} \langle P, C(\Phi)\rangle + \varepsilon \sum_{a,i} P_{ai}(\log P_{ai}-1) + \frac{\lambda}{2\sigma^2}\sum_i \|\phi_i\|^2
\]
约束为源边际 `P1 = q`（q 均匀分布），**不固定目标边际**，让代表提示根据邻域几何自适应接收质量。

- 空间匹配项：`Cai(Φ) = 1/(2σ²)·‖z_a - φ_i‖²`
- 熵正则项：控制分配的软硬程度
- L2 正则：稳定代表点

**交替优化闭式解**：
- 传输步骤：行解耦，softmax 形式更新 P
  \[
  P_{ai}^{(s)} = \frac{1}{N_u^{(t)}}\frac{\exp(-C_{ai}(\Phi^{(s-1)})/\varepsilon)}{\sum_j \exp(-C_{aj}(\Phi^{(s-1)})/\varepsilon)}
  \]
- 重心步骤：加权平均后加 L2 正则
  \[
  \phi_i^{(s)} = \frac{\sum_a P_{ai}^{(s)} z_a}{\sum_a P_{ai}^{(s)}+\lambda}
  \]
最终 `ωᵤ⁽ᵗ⁾ = MergeOT(Ωᵤ⁽ᵗ⁾) = Φ^(S)`。

#### 2.4 理论分析
- **定理 1**：证明了交替 OT 求解器的稳定性 —— 最小相邻迭代差以 O(1/√S) 速率递减。
- **定理 2**：Wasserstein 共识误差有界，且界随通信图混合系数 ρ 减小而收紧，压缩误差与梯度方差为永久性噪声源。
- **定理 3**：网络级提示重心以 O(1/T) 速度收敛到共享目标的平稳点邻域。

### 六、主要结论与发现
1. **索引错位是 DFL 提示调优的核心障碍**：按索引平均提示在异构数据下会合并语义不匹配的提示方向，准确率显著下降。
2. **OT-based 合并能有效解决该问题**：D-FROST 在 Dirichlet α=0.1 的 FiveDataset 上达到 79.36% 准确率，高于最强基线 DFedAvgM-PT（70.88%）约 8.5 个百分点；在极端非 IID 不平衡数据下优势扩大至 18.57 个百分点。
3. **拓扑越稠密（ρ 越小）优势越稳定**：在 Fully Connected（ρ≈0）下仍比最强基线高近 10 个点，证明 OT 合并的红利不依赖于某一种图结构。
4. **D-FROST 对网络降级鲁棒**：链路丢弃率 0.4 时几乎不下降（79.36%→77.29%）；扩展到 100 客户端仍有 11 个百分点优势。
5. **理论与实验一致**：共识误差与收敛界中关于图混合系数 ρ、压缩误差 δ²、梯度方差 G² 的预测在实验中均得到印证。

### 八、不足与局限
1. **理论到算法存在桥梁空隙**：定理中假设的是绝对连续测度与理想 KL 散度梯度流，但实际算法操作离散经验测度与有限 n 的压缩，常数 D（度量平移常数）没有显式计算。
