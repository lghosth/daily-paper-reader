## 摘要
图卷积网络（GCN）被广泛用于大规模图结构数据，包括社交网络、引文网络和电子商务网络，但其部署受到不规则内存访问和严重GPU工作负载不平衡的制约。这些挑战源于两个维度：由幂律度分布引起的宽度不平衡和由异质邻域连接引起的深度不平衡。我们提出了DualGCN，一个通过双度量图划分和自适应内核执行来解决这两个维度的GPU加速框架。DualGCN结合了反映聚合宽度的节点度数和通过匿名随机游走估计的邻域密度，以捕获多跳连接和访问深度。这种混合工作负载度量能够将大图划分为稀疏和密集区域，同时将工作负载不平衡从线性复杂度降低到对数复杂度。随后，DualGCN选择特定于划分的执行策略：稀疏划分利用线程束级并行和合并内存访问，而密集划分利用指令级并行来隐藏延迟并提高GPU利用率。在十二个真实世界图数据集上的实验表明，DualGCN持续加速GCN计算，相比cuSPARSE、GNNAdvisor和ACCEL分别实现了2.53倍、3.8倍和2.13倍的平均加速。这些结果表明，联合优化图划分和内核执行为处理大规模图和社会网络工作负载提供了一种有效解决方案。

## Abstract
Graph Convolutional Networks (GCNs) are widely used for large graph-structured data, including social, citation, and e-commerce networks, but their deployment is constrained by irregular memory access and severe GPU workload imbalance. These challenges arise in two dimensions: width imbalance from power-law degree distributions and depth imbalance from heterogeneous neighborhood connectivity.We present DualGCN, a GPU acceleration framework addressing both dimensions through dual-metric graph partitioning and adaptive kernel execution. DualGCN combines node degree, reflecting aggregation width, with neighborhood density estimated by anonymous random walks, capturing multihop connectivity and access depth. This hybrid workload metric enables connectivity-aware partitioning of large graphs into sparse and dense regions while reducing workload imbalance from linear to logarithmic complexity. DualGCN then selects partition-specific execution strategies: sparse partitions use warp-level parallelism and coalesced memory access, whereas dense partitions exploit instruction-level parallelism to hide latency and improve GPU utilization. Experiments on twelve real-world graph datasets show that DualGCN consistently accelerates GCN computation, achieving average speedups of 2.53x, 3.8x, and 2.13x over cuSPARSE, GNNAdvisor, and ACCEL, respectively. These results demonstrate that jointly optimizing graph partitioning and kernel execution provides an effective solution for processing large-scale graph and socialnetwork workloads.

- 现有方案的主要问题：
  - 图划分方法要么复杂度高（如基于社区检测至少O(m²/n)），要么只用节点度数信息，忽略了邻域连接模式与多跳聚合依赖；
  - GPU资源管理多为静态线程束/块分配，难以及时适应动态负载差异；
  - 对稀疏区和稠密区采用统一的内存访问策略，无法针对性优化。
- 核心目标：通过联合优化**图划分**与**GPU内核执行**，提升GCN大规模图处理效率。

## 2. 方法论：DualGCN 框架

### 2.1 总体核心思想

DualGCN是一个“算法-架构”协同设计的GPU加速框架，主要包含两大组件：

1. **连通性感知的数据划分**：通过双度量将图数据划分为稀疏与稠密区域，优化负载均衡与数据局部性；
2. **自适应双路径内核执行**：针对不同分区特征，动态分配GPU block、warp和线程资源，并匹配相应访存策略。

### 2.2 理论支撑：匿名随机游走

- 采用匿名随机游走（anonymous random walks）量化邻域聚合的计算复杂度，而不只是使用节点度数。
- **Theorem 1**：从节点v出发、d步内的匿名随机游走集合，其唯一节点数分布 \(P_d\) 的加权和 \(\sum_{i=1}^{d} iP_i\) 可表征距离≤d的子图结构密度，比单纯度指标更能刻画聚合复杂度。

### 2.3 双度量工作负载表征

- **邻域密度 \(N_v\)**：由上述 \(\sum_{i=1}^{d} iP_i\) 定义，反映多跳邻域的计算深度和内存访问模式；
- **节点度数 \(D_v\)**：反映聚合宽度，即并行化机会。
- 合成混合度量：
  \[
  H_v = \alpha N_v + (1-\alpha) D_v
  \]
  - \(\alpha\) 是权重参数（实验默认经自适应方差分析设为0.5）。
  - 通过 \(H_v\) 进行排序和连续分块，实现稀疏/稠密区域的划分。

### 2.4 平衡性理论保证

- **Theorem 2**：在最大度为\(\Delta\)的图中，该方法可将工作负载不平衡因子从朴素划分的O(Δ)降至O(log Δ)。
- 直觉：朴素随机划分可能使多个高维节点集中在同一block中；而根据双度量排序后再连续分区，相邻节点的负载相似，任意block间差异被限制，最终得到对数级不平衡度。

### 2.5 自适应内核执行

- **处理模式选择**：
  \[
  \text{Processing Mode} = \begin{cases}
  \text{Sparse Path} & H < \tau \\
  \text{Dense Path} & H \ge \tau
  \end{cases}
  \]
  其中阈值 \(\tau = \mu_H + 0.5\sigma_H\)（工作量分布均值加半个标准差）。
- **稀疏区路径**：
  - 采用warp级并行，多个warp分组处理多行；
  - 每个warp同一时刻处理一个特征，所有warp同步推进特征范围；
  - 保证合并内存访问（coalesced memory access），消除线程发散；
  - 共享内存用量低，寄存器约8–10个/线程。
- **稠密区路径**：
  - 一个block处理单行，行内再细分到多个warp；
  - 采用4路指令级并行（4-way ILP），每个线程维护4个独立累加器；
  - 通过交错访存（stride = block_size × 4）实现合并访问，同时利用`__ldg()`绕过L1、访问只读缓存；
  - 共享内存分配512B–2KB，寄存器16–20个/线程。
- **资源管理原则**：
  - 根据 \(D_v\) 决定warp数量；高维节点分配多warp，低维节点共享warp；
  - 根据 \(N_v\) 影响寄存器和ILP配置；
  - block级采用方差最小化分区，合理分配SM负载。

### 2.6 时间复杂度与开销

- 预处理总复杂度O(|V|(kd + log|V|))，其中k、d为常数；
- 可分摊到训练epoch中，每个迭代额外开销为O((kd+log|V|)/T)，实际开销很小。
