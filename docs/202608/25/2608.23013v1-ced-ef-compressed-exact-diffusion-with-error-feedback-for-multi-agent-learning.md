## 摘要
我们研究了在一个由N个智能体组成的网络上的分散随机优化，在压缩通信下。我们提出了CED-EF，一种基于精确扩散的带误差反馈的方法，直接适应有偏的δ-收缩压缩器，同时每个节点每次迭代传输一个压缩的模型大小向量。对于光滑非凸目标，具有方差由σ²界定的无偏随机梯度，其中σ≥0，我们建立了一个收敛速率，其主导随机项为O(σ/√(NK))。对于σ>0，相应的瞬态时间对智能体数量、压缩水平和谱间隙Δ_λ的主要依赖是O(N³/(δ⁴Δ_λ⁴))，固定的问题相关因子被抑制。在Polyak--Łojasiewicz条件下，CED-EF达到主导随机项为O~(σ²/(NK))，瞬态时间约为O~(N/(δ²Δ_λ²))。这些依赖改进了现有结果的压缩和/或网络依赖。在最小二乘和逻辑回归问题上的数值实验说明了CED-EF的性能优势。

## Abstract
We study decentralized stochastic optimization over a network of $N$ agents under compressed communication. We propose CED-EF, an exact diffusion-based method with error feedback that directly accommodates biased $δ$-contractive compressors while communicating one compressed model-sized vector per node per iteration. For smooth nonconvex objectives with unbiased stochastic gradients whose variance is bounded by $σ^2$, where $σ\geq0$, we establish a convergence rate whose leading stochastic term is $\mathcal O(σ/\sqrt{NK})$. For $σ>0$, the dominant dependence of the corresponding transient time on the number of agents, compression level, and spectral gap $Δ_λ$ is $\mathcal O(N^3/(δ^4Δ_λ^4))$, with fixed problem-dependent factors suppressed. Under the Polyak--Łojasiewicz condition, CED-EF attains a leading stochastic term $\widetilde{\mathcal O}(σ^2/(NK))$ with transient time on the order of $\widetilde{\mathcal O}(N/(δ^2Δ_λ^2))$. These dependencies improve the compression and/or network dependence of existing results. Numerical experiments on least-squares and logistic-regression problems illustrate the performance advantages of CED-EF.

## 1. 核心问题与整体含义（研究动机与背景）

- 论文研究**多智能体网络上的分布式随机优化问题**：每个智能体拥有本地数据分布和本地损失函数，目标是通过仅与邻居交换信息的方式，协作最小化全局平均风险函数。
- 在分布式机器学习中，通信通常是主要瓶颈，尤其当模型维度很高时。为降低通信代价，主流策略分为两类：
  1. 在通信间隙执行多次本地更新；
  2. 对通信消息进行压缩。
- 论文聚焦于**带压缩通信的去中心化优化**，但现有方法存在若干问题：
  - 多数压缩方法只支持无偏压缩算子（如随机稀疏化），而有偏但高效且常见的压缩算子（比如确定性 Top-c 稀疏化）则更难被接纳。
  - 已有的支持有偏压缩的方法（如 BEER、MoTEF）要么每轮需传输两个压缩模型量，要么网络依赖更差。
  - 在非凸环境下，保留线性加速（即收敛主导项为 O(σ/√(NK))）并同时支持有偏压缩，此前尚无基于精确扩散（Exact Diffusion, ED）的方法能够实现。
- 因此，本文提出 **CED-EF**（Compressed Exact Diffusion with Error Feedback），将精确扩散与误差反馈机制结合，直接在有偏 δ-收缩压缩器下工作，**每节点每轮只传输一个压缩模型大小的向量**。
- 研究的意义在于：为有偏压缩场景下的分布式非凸优化提供了理论完备、通信高效且网络依赖更优的解决方案。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想

- 以**精确扩散（ED）**为基础框架，通过引入**误差反馈（Error Feedback）**来补偿压缩引入的有偏误差，使算法既能利用 ED 在异质性数据下的偏差校正能力，又能直接兼容有偏压缩器。
- 关键创新在于：尽管压缩是有偏的，算法依然保留了对全局最优解的精确收敛性，而非仅仅收敛到一个有偏解。

### 关键技术细节

- 每个节点维护以下变量：
  - 主变量 \(x_k^i\)、对偶变量 \(y_k^i\)（控制变量/校正项）；
  - 压缩误差变量 \(e_k^i\)，累积压缩误差并反馈到后续压缩消息中；
  - 两个辅助代理变量 \(\phi_k^i\) 与 \(\psi_k^i\)。
- 算法每轮执行以下更新：
  1. 计算代理点 \(\hat{x}_k^i = x_k^i - \alpha \nabla F_i(x_k^i; \xi_k^i) - y_k^i\)；
  2. 形成压缩消息 \(q_k^i = \mathcal{C}_i(\hat{x}_k^i - \phi_k^i + \eta e_k^i)\)；
  3. 更新误差 \(e_{k+1}^i\)、变量 \(\phi_{k+1}^i\)、\(\psi_{k+1}^i\) 与 \(x_{k+1}^i\)；
  4. 通过对偶更新更新控制变量 \(y_{k+1}^i\)。
- 参数包括梯度步长 \(\alpha\)、共识参数 \(\gamma\)、原始与对偶混合权重 \(\beta\)、\(\theta\)，以及误差反馈泄漏参数 \(\eta\)。
- 当压缩器为恒等算子（\(\mathcal{C}=\mathrm{I}\)）且 \(e_0=0\) 时，误差变量恒为零，算法退化为标准精确扩散。

### 理论结果

- **非凸光滑目标**：在随机梯度方差有界（界为 \(\sigma^2\)）条件下，算法达到如下遍历性收敛率：
  \[
  \frac{1}{K}\sum_{k=0}^{K-1}\mathbb{E}\|\nabla f(\bar\phi_k^e)\|^2
  \le \mathcal{O}\left(\frac{\sigma}{\sqrt{NK}}\right)
  + \text{低阶项},
  \]
  其中主导随机项与中心化随机梯度法的线性加速一致。
- 对 \(\sigma>0\)，瞬态时间（线性加速生效所需的迭代数）的主导依赖为：
  \[
  \mathcal{O}\left(\frac{N^3}{\delta^4\Delta_\lambda^4}\right).
  \]
- **Polyak–Łojasiewicz（PL）条件**：主导随机项提高到 \(\widetilde{\mathcal{O}}(\sigma^2/(NK))\)，瞬态时间降至：
  \[
  \widetilde{\mathcal{O}}\left(\frac{N}{\delta^2\Delta_\lambda^2}\right).
  \]
- 对无偏压缩器参数 \(C\)，CED-EF 的非凸瞬态时间依赖为 \(C^4\)，PL 场景为 \(C^2\)，均优于 CEDAS 的 \(C^6\) 与 \(C^3\)。
- 收敛性证明采用**矩阵特征分解**将网络动态解耦，结合**林雅普诺夫函数**分析质心演化、不一致动态与压缩误差动态，并给出参数可满足的充分性条件。

## 3. 实验设计

### 实验场景一：合成数据上的正则化最小二乘

- 目标函数形式：
  \[
  f_i(x) = \frac{1}{2M}\|A_i x - b_i\|^2 + \frac{\lambda_{\text{reg}}}{2}\|x\|^2,
  \]
  其中 \(M=200\)，\(n=10\)，\(\lambda_{\text{reg}}=10^{-3}\)。
- 设计矩阵随机生成，并控制条件数与数据异质性；响应向量由归一化真值加噪声生成。
- 设置了**随机梯度**实验（mini-batch \(B=25\)）与**全梯度**确定性实验。

### 实验场景二：真实数据（LIBSVM a9a）上的逻辑回归

- 采用带饱和非凸正则项的逻辑回归：
  \[
  f_i(x) = \frac{1}{M}\sum_{j=1}^{M}\log\left(1+\exp(-b_{ij}a_{ij}^{\top}x)\right)
  + \lambda_{\text{reg}}\sum_{\ell=2}^{n}\frac{x_\ell^2}{1+x_\ell^2},
  \]
  数据集取 a9a 的 20,000 个样本，划分为 \(N=20\) 个节点，每节点 1000 个样本。
- 随机梯度场景使用 Top-5 压缩，mini-batch 大小为 64。

### 网络拓扑与基础设置

- 使用两种图拓扑：
  - **指数图**（谱间隙约 0.44，连通性较好）；
  - **线图**（谱间隙约 \(8.2\times10^{-3}\)，连通性较差）。
- 使用 Metropolis–Hastings 规则构造对称双随机混合矩阵。
- **压缩器**统一使用 Top-c（保留 c 个最大幅值坐标），满足 \(\delta = c/n\)。
- 通信成本按**压缩向量传输次数**计（CED-EF 与 CEDAS 每轮一个向量，BEER 与 MoTEF 每轮两个向量）。

### 对比方法（Benchmark）

1. **CEDAS**：基于 ED 的压缩方法，理论假设无偏压缩，但实验中仍使用有偏 Top-c 以做统一对比；
2. **BEER**：基于梯度追踪的有偏压缩方法，需传输两个压缩量；
3. **MoTEF**：动量追踪 + 误差反馈，同样需传输两个压缩量。

### 额外实验

- 在最小二乘问题中评估**不同压缩级别**（Top-1、Top-3、Top-5、不压缩）对通信效率的影响，以**传送位数**为横轴展示压缩带来的实际通信节省。

## 6. 论文的主要结论与发现

1. CED-EF 同时具备以下性质：
   - 直接支持有偏 δ-收缩压缩器；
   - 每轮每节点仅需传输一个压缩模型向量；
   - 在光滑非凸目标下达到线性加速收敛主导项 \(\mathcal{O}(\sigma/\sqrt{NK})\)；
   - 在 PL 条件下达到 \(\widetilde{\mathcal{O}}(\sigma^2/(NK))\) 的主导随机项。
2. 瞬态时间对网络和压缩的依赖显著优于现有方法（见表 1）：非凸场景为 \(\mathcal{O}(N^3/(\delta^4\Delta_\lambda^4))\)，PL 场景为 \(\widetilde{\mathcal{O}}(N/(\delta^2\Delta_\lambda^2))\)。
3. 与梯度追踪类压缩方法（BEER、MoTEF）相比，CED-EF 通信量减半，且网络连通性差时性能退化更温和。
4. 数值实验表明 CED-EF 在达到同等精度的通信代价上通常优于对比方法，尤其在连通性差的网络和确定性场景下优势更明显。
5. 压缩级别实验说明，在通信受限时，采用较强压缩（如 Top-3/Top-5）可以显著节省总通信比特数，同时保持收敛性能。

## 7. 优点

### 理论贡献

- **首次**在基于精确扩散的框架下，针对有偏压缩器建立非凸线性加速收敛保证。
- 与已有方法（CEDAS、BEER、MoTEF）相比，在压缩级和网络级依赖上均有改善。
- 对无偏压缩器还可通过缩放将其归入有偏框架，得到更好的依赖（\(C^4\) vs. \(C^6\)）。
- 理论分析框架（对角化 + 林雅普诺夫函数）较为完整，提供了参数选择的显式充分条件。

### 算法设计

- 通信代价低：每节点每轮仅传一个压缩向量，而梯度追踪类方法需要两个。
- 参数灵活：允许在较宽范围内选择参数，并直接适配有偏确定性压缩器（如 Top-c）。
- 在无压缩时可退化为标准精确扩散，具有较好的兼容性。

### 实验验证

- 在两类图拓扑上系统比较了不同算法，结果与理论预测一致，尤其在网络更差的线图上 ED 类方法优势显著。
