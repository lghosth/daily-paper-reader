## 摘要
在分布式优化中实现局部差分隐私同时保持低通信成本仍然具有挑战性。现有的向量量化方法（如vqSGD）使用高维几何构造，但会产生不利的维度相关方差。在这项工作中，我们提出了子采样随机TurboQuant（SSTQ），这是一个结合了过完备等范数紧框架、坐标子采样和隐私感知一维量化的框架。SSTQ包含两个变体：平坦随机响应版本和度量感知拉普拉斯版本，后者更适合较高的码本位宽设置。我们证明了SSTQ在每客户端仅使用$\lceil \log_2 N \rceil + b$位的情况下实现了最优均方误差缩放，其中$N = Θ(d)$是框架大小。我们还推导了一个替代的隐私感知码本目标，将码本相关的MSE缩放从$O(4^b)$降低到$O(2^b)$。最后，我们在使用CIFAR-10和Fashion-MNIST的联邦学习任务上对SSTQ与既定基线进行了实证评估，展示了良好的效用性和通信效率。

## Abstract
Achieving local differential privacy in distributed optimization while maintaining low communication cost remains challenging. Existing vector quantization methods, such as vqSGD, use high-dimensional geometric constructions but incur unfavorable dimension-dependent variance. In this work, we propose Subsampled Stochastic TurboQuant (SSTQ), a framework that combines overcomplete equal-norm tight frames, coordinate subsampling, and privacy-aware one-dimensional quantization. SSTQ includes two variants: a Flat Randomized Response version and a Metric-Aware Laplace version, the latter being better suited to higher codebook bit-width regimes. We show that SSTQ achieves optimal mean squared error scaling while using only $\lceil \log_2 N \rceil + b$ bits per client, where $N = Θ(d)$ is the frame size. We also derive a surrogate privacy-aware codebook objective that reduces the codebook-dependent MSE scaling from $O(4^b)$ to $O(2^b)$. Finally, we empirically evaluate SSTQ against established baselines on federated learning tasks using CIFAR-10 and Fashion-MNIST, demonstrating favorable utility and communication efficiency.

- **背景**：联邦学习（FL）和大规模分布式优化面临两大挑战——**通信瓶颈**（梯度传输成本高）与**本地差分隐私（LDP）**（客户端数据需在不可信聚合器前得到保护）。压缩和隐私噪声本质矛盾：压缩减少信息，LDP需要噪声并保证不同输入的输出概率相近。
- **现有方法局限**：
  - **vqSGD**：使用高维交叉多胞体几何量化，通信量对数级，但方差随维度呈立方增长（\(\Theta(d^3/\epsilon^2)\)），高维下不可用。
  - **SQKR**：基于Kashin表示的二元量化，理论上最优，但需要1-bit/系数或对子采样施加严格限制（公共随机数、指数惩罚），通信或方差代价高。
  - **PrivUnit**：达到最优方差\(O(d/\epsilon^2)\)，但需传输连续向量，带宽不可接受。
  - **TurboQuant**：优秀的数据无关量化器，但不提供隐私，且输出位数随维度线性增长。
- **本文目标**：设计同时满足**纯\(\epsilon\)-LDP**、**低通信成本**（\(\lceil\log_2 N\rceil + b\) bits/client），并达到**最优MSE缩放**\(O(d/(1\wedge\epsilon\wedge\epsilon^2))\)的向量量化框架。
- **整体含义**：SSTQ把“高维几何问题”转化为“一维标量量化 + 坐标子采样”问题，解耦码本大小与维度，从而规避维度诅咒，建立通信-隐私-精度之间的更优权衡。

## 方法论

### 核心思想
结合三类技术：
1. **过完备等范数紧框架（ENTF）**：用 \(N=\Theta(d)\) 个冗余向量表示 \(d\) 维向量，通过Kashin表示保证每个系数均匀有界（\(|y_j|\le K/\sqrt{N}\)），降低单坐标敏感性。
2. **数据无关的坐标子采样**：客户端均匀随机采样一个Kashin系数，只量化并传输这一标量。
3. **隐私感知的一维量化码本**：对采样系数进行随机量化，再通过Flat Randomized Response或Metric-Aware Laplace机制施加LDP。

### SSTQ算法流程（Flat-RR版）
- **编码（客户端）**：
  1. 用Lyubarskii算法计算Kashin表示系数 \(y\in\mathbb{R}^N\)，满足 \(x=(d/N)U^\top y\) 且 \(\|y\|_\infty\le B=K/\sqrt{N}\)；
  2. 均匀采样索引 \(j\sim \mathrm{Unif}(1,N)\)，取系数 \(y_j\)；
  3. 在码本 \(\Gamma=\{c_1,\ldots,c_M\}\) 中找到相邻码字 \([c_k,c_{k+1}]\)，按线性插值概率随机量化到 \(v\in\{c_k,c_{k+1}\}\)；
  4. 对 \(v\) 施加Flat Randomized Response（\(e^\epsilon/(e^\epsilon+M-1)\) 保留，否则 \(1/(e^\epsilon+M-1)\) 随机替换）；
  5. 传输 \((j,z)\)，共 \(\lceil\log_2 N\rceil+b\) bits。
- **解码（服务器）**：
  1. 用 \(1/(p-q)\) 对 \(z\) 去偏得到 \(\tilde{y}_j\)；
  2. 构造1-稀疏向量 \(\tilde{y}=N\tilde{y}_j e_j\)；
  3. 通过ENTF投影 \(\hat{x}=(d/N)U^\top\tilde{y}\) 恢复估计。

### 理论保证
- **定理3.1**：Flat-RR版严格纯\(\epsilon\)-LDP，且无偏（\(E[\hat{x}]=x\)）。
- **定理3.2**：MSE上界 \(O(d(1+4^b/(\epsilon\wedge\epsilon^2)))\)。
- **代理码本优化（\(L_{SSTQ}\)）**：提出凸目标（空间量化误差 + 正则项 \(1/(e^\epsilon-1)\sum c_i^2\)），全局严格凸，最优码本将MSE从\(O(4^b)\)降为\(O(2^b)\)（定理4.3）。
- **Metric-Aware Laplace变体**：用截断Laplace采样（中心为真值码字，尺度与\(\epsilon\)相关）再最近码字量化，避开RR的\(O(2^b)\)惩罚。虽引入有界偏差（与\(d\)和\(b\)无关），但方差显著降低，适合\(b\)较大场景（定理5.1/5.2）。
- **收敛性分析**：给出非凸联邦SGD的一般收敛率，并分别导出Flat-RR版（无偏、方差\(O(d2^b/(\epsilon\wedge\epsilon^2))\)）和Metric-Aware版（有偏、方差\(O(d(1+1/\epsilon+1/\epsilon^2))\)）的率。

## 主要结论与发现

- SSTQ实现了**信息论最优的MSE缩放** \(O(d/(1\wedge\epsilon\wedge\epsilon^2))\)，同时通信量仅\(\lceil\log_2 N\rceil+b\) bits，且不需要共享随机性（private-coin）。
- 码本优化显著改善Flat-RR的MSE：从\(O(4^b)\)降至\(O(2^b)\)（理论）；实验中比uniform码本降低7–8倍MSE。
- Flat-RR在小\(b\)时表现良好，但随\(b\)增大方差急剧膨胀（与\(M^2\)成正比）；Metric-Aware在\(b=8\)时几乎不受影响，充分证明其在高位宽下的优势。
- vqSGD在\(d=25450\)甚至更小维度即发散，验证了其\(\Theta(d^3/\epsilon^2)\)的维度诅咒。
- 通信效率上，SSTQ在Fashion-MNIST上以20 bits达到63.3%准确率，接近SQKR的63.2%（64 bits）和PrivUnit的63.3%，通信量减少3.2倍；CIFAR-10上以22 bits达到19.1%，SQKR为21.0%（72 bits）。
- 理论收敛分析表明：无偏的Flat-RR版本可收敛到精确最优点；有偏的Metric-Aware版本收敛到非稳定邻域，但偏差与维度无关（\(O(G^2\epsilon^{-2})\)），适合大规模模型。

## 优点

- **理论深度**：同时给出严格LDP、无偏性、MSE上界、全局凸码本优化、非凸SGD收敛率，形成完整理论框架。
- **通信-隐私-精度三者的权衡接近最优**：比特数\(O(\log d + b)\)，方差\(O(d/\epsilon^2)\)，且无公共随机数假设。
- **设计巧妙**：用Kashin表示+1-稀疏子采样把高维问题降为一维，彻底避开几何方法的维度诅咒。
- **两个变体互补**：Flat-RR无偏、低\(b\)好；Metric-Aware有界偏差、高位宽稳定，用户可按场景选型。
- **实验验证充分**：不仅做下游准确率，还直接测量MSE缩放、码本位宽影响、线性回归收敛，佐证理论结论。

## 不足与局限

- **计算开销高**：Kashin迭代法耗时巨大（占99%+），每秒只能处理极少样本，不适合快速在线联邦训练。
- **范围假设**：需预先设定通信预算和数据范围（码本边界\([-B,B]\)），对非平稳数据或未知分布鲁棒性不足。
- **Metric-Aware有固有偏差**：偏差虽与维度无关，但仍限制收敛精度，某些高精度场景不适用。
- **实验规模有限**：仅单隐层全连接、100轮、单CPU，未见大规模数据集（如ImageNet）、现代CNN/Transformer模型或分布式GPU训练。
- **隐私预算描述**：论文报告的是per-round \(\epsilon\)，累计隐私需组合放大；实际应用中用户需额外处理。
- **未与更多先进压缩方法对比**（如其他差分私有压缩、低精度梯度压缩等），也未开放代码/复现细节中的完整超参搜索。
