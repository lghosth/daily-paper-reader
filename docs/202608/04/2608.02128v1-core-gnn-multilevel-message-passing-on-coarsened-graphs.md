## 摘要
在大型图上训练图神经网络面临着存储所有层节点表示的内存成本挑战。我们展示了若干现有的可扩展方法可以被写成GNN传播矩阵的结构化修改，提供了一个统一的视角，揭示了它们各自的局限性。特别是，图粗化将其替换为低秩近似，从而提供谱保证，但将均匀表示分配给聚类节点；而Cluster-GCN将传播矩阵限制为簇内连接，这允许高效批处理但切断长程信息。这些是对图分解为节点组的同一分解的互补失败。为了兼得两者优势，我们提出CoRe-GNN，它在每层并行执行两种传播：一个粗化的簇间项捕捉长程结构，以及一个局部簇内项保留每个节点的可区分性。我们证明了CoRe-GNN继承了与图粗化类似的近似保证，并引入了一种基于聚类的自然批处理方案，可扩展到数百万节点的图。在同质性、异质性、大规模和长程图上的节点分类基准中，CoRe-GNN优于图粗化和Cluster-GCN基线。值得注意的是，CoRe-GNN在长程任务上达到有竞争力的准确性，同时通过批处理保持内存高效。

## Abstract
Training Graph Neural Networks on large graphs is challenged by the memory cost of storing all node representations across layers. We show that several existing scalable approaches can be written as structured modifications of the GNN propagation matrix, providing a unified perspective that exposes their respective limitations. In particular, graph coarsening replaces it by a low-rank approximation that enables spectral guarantees but assigns uniform representations to clustered nodes, while Cluster-GCN restricts the propagation matrix to intra-cluster connections that allow efficient batching but sever long-range information. These are complementary failures of the \emph{same} decomposition of the graph into groups of nodes. To obtain the best of both worlds, we propose \textbf{CoRe-GNN}, which performs both propagations in parallel at each layer: a coarsened inter-cluster term capturing long-range structure, and a local intra-cluster term preserving per-node discriminability. We prove that CoRe-GNN inherits analogous approximation guarantees to those of graph coarsening, and introduce a natural cluster-based \emph{batching scheme} that scales to graphs with millions of nodes. On node classification benchmarks spanning homophilic, heterophilic, large-scale, and long-range graphs, CoRe-GNN outperforms both graph coarsening and Cluster-GCN baselines. Notably, CoRe-GNN reaches competitive accuracy on \emph{long-range} tasks, while remaining memory-efficient through batching.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：图神经网络（GNN）在大型图上的训练面临严重的内存瓶颈。标准 GNN 的每一层都需要保存所有节点的中间表示，内存成本随节点数 N 线性增长，很容易耗尽 GPU 显存（如 OGBN-products 中节点 4 跳邻居规模可达全图的 25%）。
- **现有方法的局限**：
  - **图粗化（Coarsen-GNN）**：将原始图压缩为超节点构成的小图，以低秩近似替换传播矩阵，具备谱近似保证，但同一超节点内所有节点共享相同表示，显著限制了对异质图的判别能力。
  - **Cluster-GCN**：将传播矩阵限制为簇内块对角结构，便于批处理，但完全切断了簇间（跨簇/长程）连接，长程依赖失效。
- **核心洞察**：两类方法本质上是“将图划分为节点组”这一同一分解下的互补失败：前者丢失节点级多样性，后者丢失全局结构。论文希望同时解决这两个问题。
- **整体目标**：提出 CoRe-GNN（Coarsen and Restore），在每层并行执行“粗化簇间传播”和“局部簇内传播”，兼顾长程结构与局部判别性，同时保持内存高效、可扩展到百万节点级图。

## 2. 方法论

### 2.1 统一视角：压缩图 GNN 是传播矩阵的结构化修改

- 标准 GNN 传播：`H(l) = σ(S H(l−1) θ(l))`，其中 S 为传播矩阵（如 GCN 的归一化邻接矩阵）。
- 压缩方法统一写成 `H(l) = σ(S_compressed H(l−1) θ(l))`：
  - **Coarsen-GNN**：`S_compressed = Π S Π`，其中 `Π = QP` 为粗化-提升算子，结果导致块常数表示。
  - **Cluster-GCN**：`S_compressed = S_intra`，即只保留簇内连接。

### 2.2 CoRe-GNN 架构

- **两个并行分支**（每层）：
  1. **簇间分支（coarsen）**：在粗化图上传播，用 `S_inter^c = P S_inter Q`（P 为降维矩阵，Q 为提升矩阵），捕捉长程/全局结构。
  2. **簇内分支（restore）**：在原始图节点空间传播，用 `S_intra`，保留节点级可区分性。
- 更新公式：
  ```
  H(l) = Q σ(S_inter^c P H(l−1) θ_c(l)) + σ(S_intra H(l−1) θ(l))
  ```
  其中 θ_c 和 θ 为两组独立权重。
- **与现有方法的关系**：θ_c=0 时退化为 Cluster-GCN；但 θ=0 时并不等于 Coarsen-GNN（漏掉了 P S_intra Q 项）。

### 2.3 自然批处理方案

- 维护两个并行状态：粗化空间全量超节点表示 `H_c`，以及原始空间仅当前批节点表示 `H_B`。
- 每步只对选中的簇（batch）做完整簇内传播，非 batch 的超节点用“自环代理”近似其簇内贡献。
- 训练时使用该近似（因反向传播需要保留完整计算图），但**推理时可设计精确的逐层推理**：簇间项整体在 GPU 上算，簇内项逐簇加载并立即释放，无近似。

### 2.4 理论保证

- 将 Coarsen-GNN 的传播保证（基于 Restricted Spectral Approximation 常数）推广到 CoRe-GNN。
- 定理 2 给出 CoRe-GNN 一步传播的误差上界：
  ```
  ∥Sx − (S_intra x + Q S_inter^c P x)∥_L ≤ ε_{L,Q,P,R} ∥x∥_L (C'_S + C'_Π)
  ```
  其中 `C'_S = ∥S_inter∥_L`，`C'_Π = ∥Π S_inter∥_L`，常数与 S_inter 相关而非全 S。
- 在合成 SBM 图上，CoRe-GNN 的理论界和经验传播误差均低于 Coarsen-GNN；在真实图上理论界有时不更小，但经验误差仍通常更低（说明上界较松）。

- **批处理近似**：训练时非 batch 超节点使用自环代理，引入了额外近似；虽然推理可精确，但训练与推理的不一致可能造成偏差。
- **权重/结构限制**：未探究更复杂的跨分支交互（如共享注意力或递归粗化），多级递归扩展仅作为展望提出。
