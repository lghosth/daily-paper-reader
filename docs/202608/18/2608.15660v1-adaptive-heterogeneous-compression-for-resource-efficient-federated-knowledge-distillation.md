## 摘要
联邦学习（FL）能够进行隐私保护的分布式模型训练，但在网络边缘面临异构模型架构和有限通信资源的挑战。联邦知识蒸馏（FedKD）通过结合原型级参数聚合和跨异构模型的知识迁移，缓解了模型异构性问题。然而，传输梯度仍然会带来相当大的通信开销，而现有的压缩方法通常对客户端应用统一的策略，忽略了它们不同的模型特征和资源能力。为了解决这个问题，我们提出了一种用于FedKD的异构压缩框架，使每个客户端能够从候选策略集中选择压缩策略。我们将压缩策略选择问题形式化为非平稳随机多臂老虎机（MAB），其中每个臂对应一种压缩策略。通过联合考虑局部优化改进、全局知识对齐和执行时间，设计了一种效率感知奖励。基于这一公式，我们开发了一种用于联邦知识蒸馏的自适应异构压缩算法（ASCEND），该算法采用指数移动平均（EMA）增强的ε-贪婪策略来平衡探索和利用。在多个数据集上的实验结果表明，ASCEND能够有效适应异构模型和资源设置，在保持有竞争力的模型准确率的同时降低通信开销和训练时间。

## Abstract
Federated learning (FL) enables privacy-preserving distributed model training but faces challenges from heterogeneous model architectures and limited communication resources at the network edge. Federated knowledge distillation (FedKD) alleviates model heterogeneity by combining prototype-wise parameter aggregation and knowledge transfer across heterogeneous models. However, transmitting gradients still introduces considerable communication overhead, while existing compression approaches typically apply a uniform strategy across clients and ignore their diverse model characteristics and resource capacities. To address this issue, we propose a heterogeneous compression framework for FedKD that enables each client to select a compression strategy from a candidate strategy set. We formulate the compression strategy selection problem as a non-stationary stochastic multi-armed bandit (MAB), where each arm corresponds to a compression strategy. An efficiency-aware reward is designed by jointly considering local optimization improvement, global knowledge alignment, and execution time. Based on this formulation, we develop an Adaptive heterogeneouS Compression algorithm for fEderated kNowledge Distillation (ASCEND), which employs an exponential moving average (EMA)-enhanced $ε$-greedy policy to balance exploration and exploitation. Experimental results on multiple datasets demonstrate that ASCEND effectively adapts to heterogeneous model and resource settings, reducing communication overhead and training time while maintaining competitive model accuracy.

## 一、核心问题与整体含义（研究动机与背景）

联邦学习（FL）在边缘计算场景中面临两大核心挑战：

- **模型异构性**：不同客户端设备（如手机、IoT传感器）在计算能力、内存和通信带宽上差异显著，导致客户端需要采用异构模型架构，而传统基于参数平均的FL算法要求所有客户端使用相同模型架构，难以适用。
- **通信资源受限**：联邦知识蒸馏（FedKD）虽能通过原型（prototype）级参数聚合与跨异构模型的知识迁移解决模型异构问题，但客户端反复上传完整梯度仍带来巨大通信开销。

现有梯度压缩方法（如 Top-K、Random-K、Periodic-K）通常对所有客户端在全部训练轮次中**采用统一压缩策略**，忽略了两方面的系统性差异：

1. **客户端计算能力差异**：计算密集型的 Top-K 策略适合算力强的设备，但会压垮资源受限的设备；轻量级的 Random-K 可能损害性能。
2. **模型架构差异**：Top-K 在大模型上排序开销高，而在小模型上因更新质量更好可能优于 Random-K。

论文通过实验（图1、图2）证明：**没有任何单一压缩策略能在异构客户端上始终达到最佳性能-效率折衷**。因此，核心研究问题为：**如何为具有不同模型架构和资源能力的客户端选择合适的压缩策略，以实现训练效率与学习性能的有效平衡？**

## 二、方法论

### 1. 核心思想
提出**异构压缩框架**，允许每个客户端根据自身模型特征和资源能力，从一个候选压缩策略集 S = {Top-K, Random-K, Periodic-K} 中独立选择压缩策略。并将策略选择问题建模为**非平稳随机多臂老虎机（MAB）**，设计效率感知奖励函数，通过在线学习实现自适应决策。

### 2. 关键技术细节

**（1）梯度压缩与残差累积**
- 客户端维护残差向量，补偿压缩造成的信息损失。压缩输入为当前梯度与残差之和：uₙᵗ = eₙᵗ⁻¹ + gₙᵗ。
- Top-K 选取幅度最大的 K 个元素（排序开销高）；Random-K 随机采样 K 个索引（计算复杂度低但方差大）；Periodic-K 周期性覆盖所有坐标（平衡计算效率与收敛稳定性）。

**（2）奖励函数设计**
- 考虑到压缩策略仍需兼顾训练效率和模型性能，设计效率感知奖励：
  - **G(sₙᵗ) = ΔLₙ(t) / τₙᵗ(sₙᵗ)**，其中 τₙᵗ 为单轮总时间开销；ΔLₙ(t) 为模型改进量，由全局KD损失变化和本地损失变化加权组合：**ΔLₙ(t) = ρ[L_KD^p(ω̄ₚᵗ⁻¹) − L_KD^p(ω̄ₚᵗ)] + β[fₙ(ωₙᵗ⁻¹) − fₙ(ωₙᵗ)]**。
- 对奖励进行裁剪（clip到[−1,1]），避免数值不稳定。

**（3）MAB建模与ASCEND算法**
- **臂（Arm）**：各压缩策略；**策略**：EMA增强的 ε-greedy 策略。
- **Warm-up阶段**：每个策略先执行 h 次，以经验均值初始化效用估计 Q₀ⁿ(s)。
- **自适应阶段**：以概率 εₜ = min(1, c/√t) 随机探索；以概率 1−εₜ 选择当前效用估计最大的策略。
- **EMA效用更新**：Qₜ₊₁ⁿ(s′) = (1−η_q)Qₜⁿ(s′) + η_q·G(sₙᵗ)，以适应非平稳奖励分布。
- **回滚稳定保护（Rollback-based Safeguard）**：若检测到 KD 损失突然激增（L_KD^p(ω̄ₚᵗ) > γ·L_KD^p(ω̄ₚᵗ⁻¹)），则回滚到上一轮模型参数，并强制所有客户端下一轮统一采用 Top-K 策略，防止不稳定的压缩决策导致性能崩溃。

### 3. 理论保证
- **收敛性分析（Theorem 1）**：在非凸损失函数下，FedKD异构压缩框架的收敛率为 **O(1/√T)**，与现有FL方法一致。
