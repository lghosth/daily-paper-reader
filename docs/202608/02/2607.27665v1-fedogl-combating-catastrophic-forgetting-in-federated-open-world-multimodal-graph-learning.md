## 摘要
联邦图学习使得在不共享原始图信息的情况下，能够对分散的图数据进行协作训练。随着此类风险的发展，客户端必须从私有多模态图流中学习新出现的类别，保留历史类别，并拒绝已知类别空间之外的样本。在这种背景下，客户端必须从私有多模态图流中学习新类别，同时保留历史类别并拒绝当前已知类别空间之外的样本。核心挑战是灾难性遗忘，在联邦多模态图中，它不仅仅是分类器层面的失效：旧知识可能通过模态语义覆盖、拓扑诱导的结构侵蚀和联邦记忆碎片化而被擦除。为应对这一挑战，我们提出了\textbf{FedOGL}，一个语义-结构记忆保留框架。在客户端，FedOGL通过重放和任务启动蒸馏来保留历史决策行为，同时通过投影到全局共享的结构基上来保护图传播记忆。在服务端，FedOGL维护并传递紧凑的类别原型，以促进跨客户端的知识共享，同时不暴露原始图数据。大量实验表明，与性能最佳的基线相比，FedOGL将灾难性遗忘导致的性能下降减少了\textbf{42.67\%}，同时在下游任务上保持或提升了性能。

## Abstract
Federated graph learning enables collaborative training over decentralized graph data without sharing raw graph information. As such risks evolve, clients must learn emerging classes from private multimodal graph streams, retain historical categories, and reject samples outside the known class space. In this setting, clients must learn emerging classes from private multimodal graph streams while preserving historical categories and rejecting samples outside the current known class space. The core challenge is catastrophic forgetting, which in federated multimodal graphs is not merely a classifier-level failure: old knowledge can be erased through modality-semantic overwriting, topology-induced structural erosion, and federated memory fragmentation. To address this challenge, we propose \textbf{FedOGL}, a semantic-structural memory preservation framework. On the client side, FedOGL preserves historical decision behavior through replay and task-start distillation, while protecting graph-propagation memory via projection onto a globally shared structure basis. On the server side, FedOGL maintains and transfers compact category prototypes to facilitate cross-client knowledge sharing without exposing raw graph data. Extensive experiments demonstrate that, compared with the best-performing baselines, FedOGL reduces performance degradation caused by catastrophic forgetting by \textbf{42.67\%}, while maintaining or improving performance on downstream tasks.

- **核心问题**：论文定义了**联邦开放世界多模态图学习**（Federated Open-World Multimodal Graph Learning）——在类别增量演化（class-incremental evolution）下，多个客户端协作训练，需要同时①持续学习新出现的类别、②保留历史类别的知识、③拒绝已知类别空间之外的样本（OOD检测）。
- **核心挑战——灾难性遗忘**：论文经实证研究发现，在该场景下灾难性遗忘**不仅仅是分类器层面的失败**，而是一种**语义-结构记忆失败**，具体表现为三种耦合的失效模式：
  1. **模态语义覆盖（Modality-Semantic Overwriting）**：新类别重构模态编码器，覆盖了为旧类别学到的文本-图像语义。
  2. **拓扑诱导的结构侵蚀（Topology-Induced Structural Erosion）**：即使部分重放了标签级知识，新任务优化仍会干扰历史类别所依赖的图传播方向。
  3. **联邦记忆碎片化（Federated Memory Fragmentation）**：在部分类别、局部邻域和部分模态的交错下，旧类别证据被分割为客户端特定的语义-结构碎片，参数平均无法显式识别和整合对应的类别记忆。
- **论文含义**：这一问题的解决对于分布式环境下持续学习的安全性和可靠性至关重要——它直接关系到如何在不泄露原始数据的前提下，让联邦系统在动态开放世界中长期稳定地工作。

## 2. 论文提出的方法论

论文提出**FedOGL**——一个语义-结构记忆保留框架，围绕上述三种记忆失效模式进行针对性设计，包含三大核心模块：

### 2.1 任务锚定语义保留（Task-Anchored Semantic Retention）

- **动机**：对抗**模态语义覆盖**。当新类别到来时，语义表示通路会快速适配当前类别，但可能覆盖旧类别的模态特定语义。
- **方法**：每个客户端在阶段 t 冻结接收到的全局模型作为任务起始教师（task-start teacher）θ⁻ₖ,ₜ；在小型重放窗口上同时优化以下目标：
  - **新类别可塑性**：标准交叉熵损失 L_ce(D_t^k; θ)
  - **历史重放**：对重放的历史阶段样本施加交叉熵损失
  - **任务起始边界锚定**：在重放样本上对教师和学生模型的logits施加温度 τ 的KL散度蒸馏损失
- **开放性拒绝**：使用最大softmax概率（MSP）作为已知类别置信度，低于阈值 δ 的样本判定为OOD。

### 2.2 结构基记忆屏蔽（Structure-Basis Memory Shielding）

- **动机**：对抗**拓扑诱导的结构侵蚀**。旧类别不仅依赖分类器logits，还依赖拓扑相关的传播方向（图传播记忆）。
- **方法**：
  - **客户端残差子空间提取**：客户端从结构嵌入中减去已被全局基 Uₜ₋₁ 解释的方向，计算残差协方差矩阵，取其前 r 个特征向量作为局部结构基。
  - **服务端结构记忆聚合**：服务端通过对**投影矩阵求和**（而非直接平均基向量）来聚合局部结构记忆，保持子空间几何，生成全局结构基 Uₜ。
  - **残差梯度投影**：下一阶段训练时，将结构参数的梯度投影到 Uₜ 的零空间，即 Pₜᅪ⊥(G) = G(I − UₜUₜᵀ)，允许学习新结构模式，同时抑制覆盖历史图传播记忆的更新。

### 2.3 原型引导的记忆整合（Prototype-Guided Memory Consolidation）

- **动机**：对抗**联邦记忆碎片化**。没有客户端能观察到完整类别空间或旧类别的完整语义-结构支持，参数平均无法恢复碎片化的类别记忆。
- **方法**：
  - **类别证据融合与原型构建**：每个客户端将每个节点的语义特征、结构特征和模态可用性指示器融合为记忆描述子 z，按类别（及类别内模式）凝聚为局部原型 p 及其支持规模 n。
  - **服务端记忆更新**：服务端维护每类的有界记忆库 M_c = {(p̄, n)}。新到达的原型与最相似的槽位进行**支持规模加权合并**（若余弦相似度超过阈值 η）；否则占用空槽或替换最弱槽位。节点、边和多模态内容均不离开本地。
  - **原型图整合**：服务端构建轻量级原型图（K近邻边 + 同类边），在该原型图上对全局模型进行精炼（标签损失 + 教师蒸馏损失）。原型记忆作为紧凑的"联邦类别底物"，减少未来阶段的记忆碎片化。

### 2.4 端到端流程

每个阶段：客户端编码多模态属性图 → 在任务起始教师约束下学习当前和重放节点 → 结构梯度经全局结构基投影屏蔽 → 提取局部原型和残差结构基 → 上传模型更新与紧凑摘要 → 服务端聚合模型参数和局部基、匹配合并原型、构建原型图并精炼全局模型 → 更新后的全局模型和结构基支撑下一轮学习。

## 6. 论文的主要结论与发现

- **FedOGL在主实验中的表现**：
  - 在所有6个数据集上取得**最好或第二好**的性能，在缓解遗忘（FM）和开放世界拒绝（FPR95）方面优势最为显著。
  - FM在5个数据集上取得最低值；FPR95在5个数据集上取得最低值；AM在所有数据集上取得最好或第二好的下游任务性能。
  - 相比各指标的最强基线：**FM降低42.67%**（对比FedIIH）、**FPR95降低28.31%**（对比POWER）、**AM提升9.41%**（对比POWER）。
- **保留动态**：在Grocery四任务流上，每个历史任务在学习完全部任务后精度保持在65.2%–70.6%范围内，每个阶段后的平均已见任务精度始终高于所有基线。
- **消融结论**：移除任何组件都会导致性能下降。其中重放对FM的影响最大，蒸馏、结构投影和原型传输提供互补收益。
- **联邦规模**：随客户端数量从5增至15，性能逐渐下降但仍保持稳健。
- **超参数敏感性**：在默认配置附近表现最佳，相邻设置仍具竞争力，不存在"刀尖上的最优"，实际调参不需要异常精确。
- **效率**：通信成本高于轻量级基线但低于POWER；运行时间接近FedAvg，低于大部分开放世界基线。

6. **OOD检测方法相对基础**：开放世界拒绝依赖MSP阈值（Eq. 6），而近年来更先进的OOD评分方法（如能量分数、ODIN等）未被探索；MSP对阈值选择敏感，在实际部署中校准成本较高。
7. **对结构基机制的深层分析不够**：基秩 r 是重要超参数，但论文仅给出敏感性热力图，未深入讨论基秩选择与下游性能、通信开销之间的理论性权衡。
8. **潜在偏差风险**：论文第一作者与其引用的前期工作（如PRISM、MM-OpenFGL）来自同一团队，基准方法的选择和实现可能偏向于突显自身方法优势，存在一定的利益相关性风险。
9. **理论保证缺失**：论文主要依赖实证验证，对三类记忆失效的机制以及投影屏蔽、原型整合的防遗忘效果缺乏理论层面的分析与保证。
